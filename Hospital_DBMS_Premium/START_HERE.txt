MEDICORE HOSPITAL SUITE — PREMIUM SQLITE EDITION

NO MYSQL REQUIRED.

Fastest way:
1. Extract the ZIP.
2. Open the folder in VS Code.
3. Double-click run_project.bat (or run the commands below).
4. Open http://127.0.0.1:5000

Manual:
    py -m venv venv
    venv\Scripts\activate
    pip install -r requirements.txt
    python app.py
